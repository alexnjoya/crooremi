# Demo Script (≤5 min)

Lead with **payroll / treasury / revenue splits** — not "we integrated CAP."

## 0:00–0:20 — Hook

> "DAOs and AI agents still move money manually or through rigid contracts. Remifi turns a plain-English policy into automatic USDC payouts on Base."

Show typing: *"Split revenue 40% team, 30% ops, 20% treasury, 10% reinvest"*

## 0:20–1:30 — Core flow

1. `createPolicy` → structured split returned  
2. `executePaymentJob` → USDC sent to multiple addresses  
3. Open BaseScan — show real transactions  

## 1:30–3:00 — A2A moment (most important)

1. Open [Agent Store](https://agent.croo.network)  
2. Show **another team's agent** (or disclosed integration partner) hiring Remifi  
3. Narrate: "This is a different team's agent using Remifi as its payout layer."  

## 3:00–4:00 — Proof

- CAP delivery JSON with `txHashes`  
- Order completed in dashboard  
- Reputation / on-chain settlement trail  

## 4:00–5:00 — Close

- Fee model: 0.1–0.5% on routed volume  
- Vision: default settlement layer for agent payrolls and revenue splits  
- ENS identity angle: `team.remifi.eth` as payment destination
